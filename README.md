# AI Finance Assistant

AI Finance Assistant is a simple web application developed using Python, Flask, and SQLite.

## Features

- Add income and expense transactions
- Calculate total income
- Calculate total expenses
- Display current balance
- Delete transactions
- AI Finance Chatbot
- Financial saving and budgeting suggestions

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install required packages:

   pip install -r requirements.txt

2. Run the application:

   python app.py

3. Open the browser and visit:

   http://127.0.0.1:5000

## Project Purpose

This project helps users track their income and expenses and provides basic financial guidance using an AI-style chatbot.
